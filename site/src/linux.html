A thermal printer app for Linux

NuPrint prints notes, pictures and PDF pages from a Linux computer to a pocket Bluetooth thermal printer. It is free, and it needs no phone app and no printer driver.

For NuPrint {{TAG}} · 64-bit · supported printers

Install it

  • Debian and Ubuntu: NuPrint_{{VERSION}}_amd64.deb
  • Fedora and openSUSE, and any other distribution: see the files on the {{TAG}} release page (an .rpm package and an AppImage).

An AppImage needs no install. Make it executable (chmod +x, or Allow executing as program in its properties) and open it.

Check your Bluetooth version

NuPrint needs BlueZ 5.80 or newer. Check with bluetoothctl --version. Ubuntu 24.04 and older can't reach the printer.

Run these once, so NuPrint can connect to the printer over Bluetooth LE:

sudo sed -i 's/^#\?Experimental = .*/Experimental = true/' /etc/bluetooth/main.conf
sudo systemctl restart bluetooth

Don't pair the printer in your system's Bluetooth settings. NuPrint doesn't need pairing, and if you did pair it, choose Forget. The NuPrint on Linux notes explain why this is needed and what was tested.

Print in four steps

  1. Turn on the printer, load thermal paper and close any printer app on your phone.
  2. In NuPrint, open the printer button, choose Find printers… and press Save printer on yours.
  3. Write a note, or open a picture or one page of a PDF. The preview shows exactly what will print.
  4. Set darkness, copies and extra feed, then press Print.

Which printers work

The ZEITEL SC03h is tested on Linux (Fedora). More models are offered as experimental. See the full list of supported printers.
