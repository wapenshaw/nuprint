A thermal printer app for Windows

NuPrint prints notes, pictures and PDF pages from a Windows 10 or 11 PC to a pocket Bluetooth thermal printer. It is free, and it needs no phone app, no pairing and no printer driver.

For NuPrint {{TAG}} · supported printers

Install it

  • Microsoft Store: signed, so Windows doesn't warn about it, and the Store keeps it up to date. Or run winget install 9NW47STT70BG in a terminal.
  • NuPrint_{{VERSION}}_x64-setup.exe: needs no admin rights. The installer isn't code-signed yet, so if SmartScreen warns about an unrecognised app, choose More info → Run anyway.

A Store copy and an installer copy keep separate printers and queues. To switch, uninstall the one you're leaving.

Print in four steps

  1. Turn on the printer, load thermal paper and close any printer app on your phone.
  2. In NuPrint, open the printer button, choose Find printers… and press Save printer on yours. Windows doesn't need you to pair it first.
  3. Write a note, or open a picture or one page of a PDF. The preview shows exactly what will print, with a millimetre ruler beside it.
  4. Set darkness, copies and extra feed, then press Print.

Which printers work

The ZEITEL SC03h is tested on Windows. More models are offered as experimental. See the full list of supported printers.

If Windows can't find the printer

  • Check that Bluetooth is on, turn the printer off and on, and keep it close.
  • Close any phone app that may be holding the connection.
  • Connected but no status? Turn the printer off and on and check the connection again. Removing an old Bluetooth pairing for the printer in Windows settings can help.
  • Blank paper? The thermal side of the paper must face the print head.

The user guide has the rest.
