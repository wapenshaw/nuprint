Supported printers

NuPrint prints to pocket Bluetooth thermal printers. One model is tested on real hardware, and {{PRINTERS_COUNT}} more are offered as experimental.

For NuPrint {{TAG}}, the version on the download page.

Tested: the SC03h

The ZEITEL SC03h is verified on Windows, macOS and Linux. Its Bluetooth name starts with SC03h-, and the h is lowercase. A printer whose name starts with an uppercase SC03H- is a different model, and NuPrint does not print to it.

{{PRINTERS_VERIFIED}}

Experimental: {{PRINTERS_COUNT}} more models

These printers use the same settings as the SC03h in the maker's own phone app, but nobody has tried them with NuPrint on real hardware yet. NuPrint lists each one with an Experimental badge and asks you to confirm before you save it. Each model is matched by its exact Bluetooth name, so a lookalike never gets print commands by mistake.

{{PRINTERS_EXPERIMENTAL}}

Names that differ only by letter case, such as X5h- and X5H-, are different printers. Only the spelling in the table is offered.

Check your printer

  1. Turn the printer on and close any printer app on your phone.
  2. In NuPrint, open the printer button and choose Find printers….
  3. Look for a name that starts as in the tables above. A supported printer appears with a Save printer button, and an experimental one carries the badge.
  4. Press Check connection. It asks the printer how it is doing without using any paper.

A printer that isn't in the tables shows up as an unknown device. NuPrint never sends it anything.

If your printer isn't listed

If you own one of the experimental models, a printer report is the fastest way to get it tested and moved to the tested list. Print the Test pattern (under What to print), take a photo of the strip and attach a diagnostics export from Settings → Diagnostics. Device names, addresses and job titles are hidden in the export unless you choose to include them.

Other makers' printers need real protocol work before they can be added, and each one is checked on hardware first.
